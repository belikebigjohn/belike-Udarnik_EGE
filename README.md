# Ударный эфир

Telegram-бот и Mini App для пятиминутной тренировки ударений ЕГЭ. Сервер, Telegram-бот и SQLite работают на стандартной библиотеке Python; `pypdf` нужен только для повторного импорта официального PDF.

## Проверенные источники

- Пакет [демоверсии, спецификации и кодификатора ЕГЭ‑2027](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory) по русскому языку: задание **4**, пять вариантов, выбрать все слова с верно выделенной ударной гласной и записать номера. В демонстрационном варианте правильные номера **1, 2, 4, 5**. Спецификация относит задание 4 к нормам ударения.
- Отдельного орфоэпического списка в архиве 2027 года нет. База взята из официального [«Орфоэпического списка — 2026»](https://doc.fipi.ru/navigator-podgotovki/navigator-ege/2026/ru-1-fonetika.pdf), рекомендованного самим навигатором ФИПИ для задания 4.
- `source/` содержит скачанные оригиналы и текстовые извлечения для аудита. `data/words.json` содержит 220 явно напечатанных форм: исходную строку, страницу, категорию, пояснение и сноску. Никакой генерации словоформ нет. Контрольная сумма PDF и распределение записей находятся в `data/import-report.json`.
- ФИПИ отмечает, что в реальных КИМ слово из списка может встретиться в другой грамматической форме. Приложение намеренно тренирует только явно напечатанные формы. Одно исключение — точный пример задания 4 из демоверсии 2027: неверное «накрЕнятся», для которого в списке напечатана опорная форма «накренИтся». Его ответ проверен по ключу демоверсии; в динамические задания эта форма не добавляется.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
python import_fipi.py
$env:DEV_MODE='1'
python app.py
```

Откройте `http://127.0.0.1:8080/`. В режиме `DEV_MODE=1` браузер использует тестового пользователя `1`, даже если `BOT_TOKEN` уже загружен в окружение. Сервер слушает только `127.0.0.1`, а Telegram polling в этом режиме не запускается. Прогресс записывается в `data/progress.sqlite3`.

## Telegram и размещение

1. Создайте бота через BotFather и подготовьте HTTPS-домен для Mini App. Telegram требует HTTPS URL.
2. Скопируйте `.env.example` в `.env`, задайте `BOT_TOKEN`, `APP_URL`, `PORT` и при необходимости `DATABASE_PATH`. Сервер **не читает `.env` сам**: передайте переменные окружения через менеджер сервиса или загрузите их локально. Не включайте `DEV_MODE` на публичном сервере.
3. Запустите `python app.py` за HTTPS reverse proxy. Установите один экземпляр процесса: один процесс выполняет Telegram long polling и ежедневные напоминания. Дайте сервису постоянный диск для SQLite и резервного копирования.
4. При старте бот сам выставляет команды и кнопку Mini App в меню. `/start` объясняет игру и присылает кнопку «Открыть тренировку». Напоминания изначально выключены; их можно включить в приложении или `/remind_on` и выключить там же или `/remind_off`.
5. `REMINDER_HOUR_UTC` задаёт час отправки по UTC всем согласившимся пользователям. Отправка не чаще одного раза за календарный день UTC.

Все приватные API-запросы проверяют Telegram `initData`: HMAC-SHA-256 по токену бота, возраст не больше 24 часов и Telegram user ID. Данные и прогресс хранятся по ID на сервере, поэтому переходят между устройствами. Ключи ответов сервер не отдаёт до отправки ответа.

## Логика запоминания

В выпуске 10 начальных слов, до 15 карточек с повтором ошибок. Ошибка вставляет слово после нескольких карточек и назначает повтор на следующий день. Правильные ответы в **разные дни** увеличивают `streak_days`; три дня дают статус «изучено». Интервалы после первого, второго, третьего и дальнейших дней: 1, 3, 7 и 14 дней. Ошибка сбрасывает серию. «Пора повторить» — записи с наступившим сроком; «пока путаю» — записи с ошибкой без статуса освоения. Аудио не воспроизводится, пока нет проверенной записи.

## Проверка

```powershell
python -m unittest discover -s tests -v
node tests/ui.test.cjs
```

Тесты проверяют воспроизводимость импорта, ключ задания 4, возвращение ошибочного слова, освоение в разные дни, сохранение между соединениями SQLite, подпись Telegram, а также отдельные позиции одинаковых гласных на игровом экране. Для просмотра данных откройте `data/words.json` и сопоставьте `source_line` и `source_page` с оригинальным PDF.
